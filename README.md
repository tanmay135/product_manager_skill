# Product Manager Skill - User Guide

## What This Skill Does

The **Product Manager Skill** helps you create comprehensive, research-backed Product Requirements Documents (PRDs) for any feature or product. It automates the entire PRD creation process including:

✅ **Market Research** - Analyzes market landscape, trends, and opportunities  
✅ **Competitive Analysis** - Researches competitors and identifies differentiation  
✅ **Problem Discovery** - Documents user pain points with evidence  
✅ **Solution Design** - Defines features, user stories, and flows  
✅ **Professional Documentation** - Creates detailed PRDs with diagrams and tables

## How to Install

1. Download the `product-manager.zip` file
2. Go to your Claude settings
3. Navigate to the Skills section
4. Click "Upload Skill" 
5. Select the `product-manager.zip` file
6. Enable the skill

## How to Use

Once installed, simply tell Claude what feature you want to document. The skill will automatically trigger when you:

### Example Requests

**Simple:**
- "Draft a PRD for a dark mode feature"
- "Create product requirements for user authentication"
- "Document a notification system"

**Detailed:**
- "I want to build a calendar integration for our app. Can you research the market, analyze competitors, and draft a comprehensive PRD?"
- "Draft a PRD for adding AI-powered search to our product. Include competitive analysis and user flows."

**Research-Focused:**
- "Research competitors in the project management space and create a PRD for task dependencies"
- "Analyze the market for video conferencing features and draft requirements"

## What You'll Get

For each PRD request, Claude will:

1. **Ask Clarifying Questions** (if needed) - To understand scope, users, constraints
2. **Conduct Market Research** - 5-10 web searches to understand the landscape
3. **Analyze Competitors** - Researches 3+ competitors in detail
4. **Create Comprehensive PRD** - A professional Word document (.docx) with:
   - Executive Summary
   - Problem Statement with evidence
   - Market Research & Competitive Analysis
   - Proposed Solution with user flows
   - Detailed Requirements (functional & non-functional)
   - Implementation Plan with phases and timeline
   - Success Metrics & KPIs
   - Risk Assessment
   - Go-to-Market Strategy
   - Visual Diagrams (user flows, architecture)
   - Professional Tables (competitors, features, metrics)

## Tips for Best Results

**Be Specific:** The more context you provide, the better the PRD will be.
- ✅ "Draft a PRD for real-time collaboration in our document editor, similar to Google Docs"
- ❌ "Make a PRD for collaboration"

**Provide Context:** Share relevant information about your product, users, and goals.
- Your target audience
- Existing product capabilities
- Business constraints or priorities
- Technical limitations

**Iterate:** Review the PRD and ask for adjustments or additional details.
- "Add more details about the technical architecture"
- "Include more user stories for the mobile experience"
- "Expand the competitive analysis section"

## Example Workflow

```
You: "I need a PRD for adding team workspaces to our project management app"

Claude: [Uses product-manager skill]
- Asks clarifying questions about your app and goals
- Researches project management workspace features
- Analyzes competitors (Asana, Monday.com, ClickUp, etc.)
- Identifies user pain points and opportunities
- Designs solution with user flows
- Creates comprehensive PRD document

Result: Professional PRD document with market research, competitive analysis, 
detailed requirements, user flows, and implementation plan.
```

## Customization

- "Make the timeline more aggressive"
- "Add a section on data privacy considerations"
- "Include more technical specifications for the API"
- "Expand the go-to-market section"
- "Add user stories for the admin role"
